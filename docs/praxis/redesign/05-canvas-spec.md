# 05 · 画布工作台交互规格 v1

> 2026-11-04 · 与 `07-graph-contract.md` 同源。本文定义布局、状态呈现、交互与键盘；不定义 engine 语义。
> 视口 1440×1000，1× DPR；以下尺寸均为 CSS px。原型见 `prototypes/01-empty.html`、`02-running.html`、`03-blocked.html`。

## 1. 一屏结构

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 运行条 56   PRAXIS│Run 名/版本 · 状态·阶段·10段进度 · 已走过│唯一主动作 │
├────┬────────────────────────────────────────────────┬────────────────┤
│48  │ 画布 flex（24 点阵）                            │ 检查器 360     │
│rail│ 节点 160×84 · 节距 204 · 行距 148               │ 无选中时隐藏   │
│    │ 图块 976×316，fit 后居中                        │                │
├────┴────────────────────────────────────────────────┴────────────────┤
│ 源码抽屉 30（收起）/ 280（展开）                                       │
└──────────────────────────────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 默认 | 说明 |
|---|---|---|---|
| 运行条 | 高 56，通栏 | 常驻 | 阶段、状态、进度、唯一动作 |
| 左侧 rail | 宽 48 | 常驻 | 画布 / Run / 调色板 / 源码 / 审计 |
| 画布 | 1392×914；检查器开时 1032×914 | 常驻 | 纸面、节点、边、HUD |
| 检查器 | 360×914 | 无选中隐藏 | 契约/产物/证据/动作 |
| 源码抽屉 | 高 30 / 280 | 收起 | 与画布同一 schema |
| Run 列表 | 宽 320 抽屉 | 收起 | 覆盖 rail，不挤压画布 |

深色为下一轮 token 映射（纸白→#151513、石墨→#ece8db、状态色提亮），本轮只交付亮色。

## 2. 必须先回答的三个问题

### 2.1 打开后 3 秒内看到什么

有活动 Run 时，首屏只有三件东西：
1. 运行条左端：Run 名、当前阶段、状态词（进行中/阻塞/失败）、10 段进度；
2. 画布中部：青色当前节点（带旗标）、绿色已走路径、灰色未来节点；阻塞时 Gate 变琥珀并带原因旗标；
3. 运行条右端：唯一深色主动作（“运行实验”“冻结预注册”）。

无 Run 时：顶部“尚无 Run + 选剧本 + 命名 + 开始 Run”；画布是 10 个虚线幽灵节点，先说明“这条路有多长”。
首屏不出现：契约字段、JSON、审计、Run 列表、节点清单、设置。首屏决策字段 ≤ 12。

### 2.2 下一步动作在哪里

- 位置固定：运行条右端，38px 深色按钮；文案是 engine action 的用户动词，不写 API 名。
- 唯一性：同一动作最多出现两次——运行条 + 阻塞时检查器底部；不在节点、菜单、空态里重复。
- 节点不常驻按钮。点击节点 → 检查器底部出现该节点动作；active/blocked 节点本身只显示状态。
- 执行后按钮进入 pending（禁用、文案改“执行中…”），收到回执才更新节点；不乐观伪造成功。
- 不可执行时不显示禁用按钮，而是显示原因和重新可执行的条件。

### 2.3 如何回到“已走过路径”

- 运行条 10 段进度：绿=done、青=current、琥珀=blocked、灰=pending；每段 8×3、间距 3，可点击。
- 点任一段或“已走过 N 步 ▾”→ 画布顶部 44px 历史条：节点名 · 时间 · 回执 id，只读；点条目选中节点，检查器切只读回执模式。
- 键盘 `P` 进入路径模式：未来节点降到 25% 不透明度、已走边加粗；`Esc` 退出。默认不改变图。
- 历史不塞进 tooltip；耗时与回执只在历史条和只读检查器出现。

## 3. 运行条（56）

| 分区 | 宽 | 内容 |
|---|---|---|
| 品牌 | 116 | 17px 方标 + PRAXIS 等宽字 |
| Run 身份 | 弹性 ≥260 | 13.5 名称 + RUN id；副行 9.5 等宽：playbook · graph 版本 · run 版本 |
| 状态 | 352 | 状态点 7 + 状态词 + 阶段名 + 10 段进度 + n/10；副行一句原因/动作 |
| 动作 | 自适应 | “已走过 N 步 ▾” + 38px 主按钮 + ⌘↵ |

状态词：进行中（青）/ 阻塞（琥珀）/ 失败（红）/ 已关闭（灰）。点击状态词或阶段名 → 选中并聚焦 current 节点；点击进度段 → 历史条。阻塞时副行必须是“原因 + 下游等待数”，主动作必须是解阻动作；失败时主动作=“新建 Run”，回执入口留在“已走过”。
窄屏 <1100 运行条升 64 并压缩身份区；<900 进入列表视图。

## 4. 画布

- 纸面：24px 点阵（1px 点），无渐变、无投影、无卡片阴影。图块 976×316（5 列 × 2 行蛇形，首行左→右，次行右→左），节点 160×84，列间 44（节距 204），行距 148；fit 后居中，100% 即世界坐标 1:1。
- 节点解剖（最多 3 行，禁止字段堆叠）：

```text
● Prereg Gate            GATE
契约 3/3 已填 · 未冻结
○                          ○
```

  点 7px；名称 13；计数行 11（数字等宽）；类型标签 7.5 等宽；端口 5px，悬停 7px。GATE 节点用浅暖底区分，不用第二种边框。
- 状态不靠颜色单一编码：点 + 边框 + 旗标 + 计数行用词。

| 状态 | 呈现 | 计数行用词 |
|---|---|---|
| pending | 灰边灰点，内容降一级 | 等待上游 / 等待契约 |
| active | 青 1px 边框 + 1px 外环，上方青旗标 | 当前 · 待运行 |
| blocked | 琥珀边框/点 + 旗标 | 阻塞 · 未冻结 |
| failed | 红边框/点 + 旗标 | 失败 · 原因码 |
| quarantined | 45° 4px 斜纹，橙红点 | 隔离 |
| done | 绿点 + 绿边，计数行灰绿 | 已冻结 · 回执 r_xx |

- 边：pending 灰虚 3/3；done 绿实 1.4；active 青实 1.4；blocked 琥珀虚 2/3。端口类型不在低倍率硬编码成线型；zoom>1.2 时在边中点显示单字 A/C/E/V。非法连线红色 120ms + 原因，不落地。
- 选择：1px 墨色 outline offset 3；单击选中、Enter 开检查器；框选；拖动吸附 8px，Shift 锁单轴；拖背景平移；滚轮/±以指针为中心缩放（步 0.1，范围 0.25–2）；`0` 适应。位置 400ms 防抖 POST /layout，失败保留本地并标脏。
- 路径模式见 2.3。空态、阻塞态、失败态不新增卡片，只改节点与边。
- 列表视图：<900px 自动降级，或 `V` 键切换；同一 Graph 按拓扑序纵向排列，列=节点/状态/一句摘要；键盘与画布一致。

缩放 LOD（检查器始终完整）：

| zoom | 画布显示 |
|---|---|
| <0.6 | 仅状态点 + 名称；边不带箭头 |
| 0.6–1.2 | + 一行计数；旗标只显示状态词 |
| >1.2 | + 端口标签与边类型单字；HUD 显示世界坐标 |

## 5. 检查器（360）

- 打开：选中节点、Enter、点击旗标或历史条目。无选中不占位（画布全宽）。关闭：× 或 Esc；选中保留到下一次选择。
- 结构：kicker 18（节点 id）+ 标题行 32（名 + 状态 chip）+ 副行 24（类型/守护阶段）；正文滚动；底部动作坞 84。
- 正文最多 3 个可见字段行（该节点最关键的契约/产物），其余折叠：证据、技术细节默认关闭；计数右对齐等宽。
- 阻塞：正文顶部放 reason（原因码 + 一句人话 + 受影响节点数），底部只放解阻动作；冻结类写操作旁必须写“冻结后只读 / 改契约须新建 Run”。
- 只读回执模式：隐藏表单与动作坞，显示回执 id、哈希短值、时间；不可编辑。
- 字段失焦校验，错误就地一行；提交失败保留输入。

## 6. 调色板（左抽屉 216）

- 打开：`G` 或从 rail 向右拖；默认收起。
- 四个模板：阶段 Stage / 门 Gate / 角色 Actor / 结束 End；每项=名称 + 一句用途，不预填字段。
- 拖入画布：显示落点幽灵，吸附网格；新节点默认放在视口中心；Gate 必须选守护对象，否则拒绝并给原因。
- 只改 playbook 图，不改任何已存在 Run 的契约（07 §5）；打开时顶部一行提示。
- 键盘：`G` 开，↑↓ 选，Enter 插入视口中心，Esc 关。

## 7. 源码抽屉

- 收起 30（`L` 打开）；展开 280，覆盖画布底部，不压缩画布；11px 等宽、行号、无高亮主题。
- 内容=当前 Graph JSON（含 position），与画布同一 schema；Run 状态叠加只读，不写回源码。
- 编辑 → 校验 → 应用：只有“校验并应用”一个动作；V1–V9 任一失败 → 列出错误码与节点 id，不部分应用。
- 冲突 409 → “图已被更新，先刷新”，禁止覆盖；成功 → 回执 + 画布重绘；Esc 关闭不保存。

## 8. Run 列表（左抽屉 320）

- 行：名称、状态点、版本、更新时间；当前 Run 左侧 2px 青条；无嵌套卡片。
- 点击或 Enter = activate（GET /graph?runId=），画布 fit 并回到 current；Esc 关闭。
- 空：一行“尚无 Run”+ 开始按钮（与 01 同文案）。
- 切换前若有未应用的源码改动，提示“放弃修改？”；不静默丢弃。

## 9. 键盘

| 键 | 行为 |
|---|---|
| Tab / Shift+Tab | 按拓扑序遍历节点 |
| Enter | 打开选中节点检查器 |
| ←↑→↓ / Shift+方向 | 移动选中节点 1px / 10px（写 layout） |
| + / − / 0 | 缩放 / 适应 |
| / | 聚焦运行条（←→ 选阶段，Enter 进入） |
| ⌘↵ | 执行当前唯一主动作；检查器打开时为该节点动作 |
| P | 路径模式开关 |
| V | 画布 / 列表视图切换 |
| G / R / L / A | 调色板 / Run 列表 / 源码 / 审计 |
| Esc | 逐级：关抽屉 → 取消连线 → 取消选择 |
| ? | 快捷键表 |

## 10. 状态与失败语义

- 节点状态只来自 `graphStates`，客户端不推断 done；`current` = 拓扑序第一个 active/blocked。
- 命令返回：ok → 回执 toast 2.5s；blocked → 运行条 + 检查器原因；unknown → 显示“未知”且不自动重试；conflict → “版本已变，先刷新”，不覆盖写入；denied → 原因码 + actor 说明。
- 失败 Run：保留已走路径，失败节点红；运行条红 + “已走过 N 步”；主动作=“新建 Run”；历史条可读失败回执。
- 空态 Run（无 Run）：画布显示默认图幽灵，运行条由“新建条”替代，不出现伪状态。
- 审计：只以 320 抽屉回答“哪条结论缺少独立证据”，不进入首屏。

## 11. 三态验收与删除项

- 01 空态：3 秒内看到“尚无 Run / 剧本 / 开始 Run”；画布 10 个幽灵节点说明路径；唯一入口在运行条右端。
- 02 进行中：3 秒内看到当前 Experiment（青 + 旗标）、已走 4 步的绿色路径、下一动作“运行实验”。
- 03 阻塞：3 秒内看到琥珀 Prereg Gate、运行条“阻塞 · 契约未冻结 · 下游 7 个节点”、检查器 3 项契约、唯一动作“冻结预注册”。
- 自检：三份 HTML 单文件、内联 CSS、无 CDN/外链字体/图片；Chrome 1440×1000 截图通过；正文对比度 ≥4.5，pending 文字只作弱提示、不承载动作。
- 删掉旧界面：顶部 10 个 tab（观测塔/认知地图/契约/讨论/…）、常驻 RUNS+PLAYBOOKS 双列表、卡片式指标区（MAP/FRONTIER/MEAN REVERSION/ADD/EDGE）、页面内堆叠表单、DECISION 占位 chip、侧栏工作区与会话列表、装饰性大标题。理由：这些让“对象清单”占住首屏，把唯一动作埋到页面中部，直接破坏 3 秒定向与注意力效率。

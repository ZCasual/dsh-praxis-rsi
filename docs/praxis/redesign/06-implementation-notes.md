## 2. 实现中发现的真问题（不是原规格）

| 问题 | 原因 | 修复 |
|---|---|---|
| 画布高度为 0、节点不可见 | `.px-shell` 四行 grid + 条件 banner 导致 workspace 落在 auto 行 | 拆 `px-top`，两行 grid（auto / 1fr） |
| Client 改动不生效 | 捆绑 URL 的 `rev` 由包版本决定，不随文件哈希变化 | 每次客户端改动 bump `package.json` version |
| 连线无反馈 | 端口只有 pointer 事件，CDP/键盘不可达 | 改为点击式（out→in）+ 检查器 CONNECT 下拉 |
| 焦点节点看不到下游 | 相机只居中当前节点，上下文丢失 | 相机对齐“当前节点前 3 个节点” |
| `num` 未定义导致地图整页崩溃 | 重写 helpers 时漏定义 | 补 `num`；地图空态兜底 |
| `close-or-new-run` 直接显示原始码 | 状态机 nextAction 未映射到人话 | NEXT_LABEL 补全 + 未知动作回退聚焦决策节点 |
| 顶部按钮溢出 | header + runbar 无换行预算 | header 只留 刷新/新建；runbar 用紧凑进度 |
| 进度显示 1/11（实际 11/11） | `STATE_LABEL` 与 `STAGE_ORDER` 大小写不一致 | `stageKeyFor()` 归一化 |

## 3. 与设计师规格的偏差（有意）

- 没有 48px 工具 rail：DSH 侧栏已提供导航，再加 rail 是重复注意力开销。
- 没有“已走过 N 步 ▾ 历史条”：当前先用 11 段进度 + 节点状态；历史回看留到路径模式。
- 没有调色板拖入：连线与新建节点优先用检查器/源码；拖拽生成节点在 DSH 面板里收益低于复杂度。
- 检查器仍有 8 个契约字段：契约本身有 9 项，一次冻结必须填完；下一轮按“必填 5 + 高级折叠 4”再减。

## 4. 下一轮（按优先级）

1. 检查器字段分层：必填 5 项（问题/预测/验收/失败/对照），其余进“高级”。
2. 路径模式：按事件回放节点激活序列，支持回到任一 past 节点。
3. 调色板拖入 + 节点类型选择（阶段/门/角色），带服务端校验。
4. 地图节点拖拽与“未知 → 实验”跳转。
5. Dock chip 点击聚焦画布对应节点（需要 Host 路由或 workspace 导航 API）。
6. 冷启动自动脚本：从零到冻结的操作计数纳入测试。
